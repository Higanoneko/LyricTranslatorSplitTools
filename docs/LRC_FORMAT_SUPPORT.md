# LRC 格式支持

## 简介

LRC（Lyric）是一种纯文本歌词格式，广泛用于音乐播放器，包含时间戳和歌词内容支持同步显示。

## 支持的功能

- 时间戳识别：`[mm:ss.xx]` 格式
- 元数据保留：`[ar:]`、`[ti:]`、`[al:]`、`[by:]`、`[offset:]`
- 智能分割：日文/英文原文与中文翻译分离
- 格式保持：输出保持 LRC 格式
- 版权声明清理：自动删除平台版权信息
- 批量处理：目录级别批量处理

## 示例

### 输入 (song.lrc)
```lrc
[ar:MyGO!!!!!]
[ti:迷星叫]
[00:16.64]交差点の真ん中 急ぐ人に紛れて 置身十字路口正中央 混入熙来攘往的人群
[00:26.75]流行りの歌はいつも 那些流行的首首歌曲
```

### split 后输出 (song_split.lrc)
```lrc
[ar:MyGO!!!!!]
[ti:迷星叫]
[00:16.64]交差点の真ん中
[00:16.64]急ぐ人に紛れて
[00:16.64]置身十字路口正中央
[00:16.64]混入熙来攘往的人群
[00:26.75]流行りの歌はいつも
[00:26.75]那些流行的首首歌曲
```

## 播放器兼容

- Foobar2000 / AIMP / QQ 音乐 / 网易云音乐等所有支持 LRC 的播放器
