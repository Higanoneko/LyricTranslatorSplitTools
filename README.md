# 歌词处理工具 (Lyric Processor)

这是一个用于自动处理日文/英文和中文混合歌词的Python工具，可以将包含原文歌词和中文翻译的文件自动分割成独立的行。采用智能分组算法，准确识别原文（日文/英文）和翻译（中文）。

## 🎵 支持的格式

- **TXT格式**：标准文本歌词文件
- **LRC格式**：带时间戳的歌词文件

## 功能特点

- 自动识别时间戳格式 `[mm:ss.xx]`
- 智能分组算法：准确识别原文（日文/英文）和翻译（中文）
- 支持单文件处理和批量处理
- 保留歌曲元数据（标题、艺术家、专辑等）
- 多种分割策略，确保准确性
- 支持日文、英文和中文的混合歌词处理
- 自动处理版权声明和无关信息
- 保留原始文件格式（包括空行和音乐间隙）

## 文件分析

### 原始文件 (Lyric.txt)
- 包含时间戳和混合的日文/中文歌词
- 每行可能包含日文歌词和对应的中文翻译
- 示例：`[00:16.64]交差点の真ん中 急ぐ人に紛れて 置身十字路口正中央 混入熙来攘往的人群`

### 手动分割文件 (Lyric_split.txt)
- 已手动处理的文件，将原文和翻译分成独立行
- 每行都有相同的时间戳
- 示例：
  ```
  [00:16.64]交差点の真ん中
  [00:16.64]急ぐ人に紛れて
  [00:16.64]置身十字路口正中央
  [00:16.64]混入熙来攘往的人群
  ```

### 自动处理结果
本工具能够自动实现类似手动分割的效果，采用智能分组算法，将混合歌词智能分割成独立的原文和翻译行。

## 使用方法

### 命令行使用

```bash
# 处理TXT文件
python lyric_processor.py Lyric.txt -o Lyric_split.txt

# 处理LRC文件
python lyric_processor.py song.lrc -o song_split.lrc

# 自动生成输出文件名（保持原始扩展名）
python lyric_processor.py song.lrc
# 输出：song_split.lrc

# 批量处理目录中的所有歌词文件（支持.txt和.lrc）
python lyric_processor.py ./lyrics -b

# 批量处理并指定输出目录
python lyric_processor.py ./lyrics -o ./output -b
```

### Python代码使用

```python
from lyric_processor import LyricProcessor

# 创建处理器实例
processor = LyricProcessor()

# 处理单个文件
output_file = processor.process_file("input.txt", "output.txt")

# 批量处理
results = processor.batch_process("./input_dir", "./output_dir")
for filename, status, output_path in results:
    print(f"{filename}: {status}")
```

## 分割算法

工具使用智能分组算法来准确分割歌词：

### 核心算法：语言分组
基于用户建议的分组思路，将歌词分为：
- **原文组**：包含日文或英文的歌词原文
- **翻译组**：中文翻译部分

算法会尝试所有可能的分割点，找到最能区分原文和翻译的位置。

### 辅助策略

1. **空格分割**：识别明显的空格分隔
2. **中文检测**：查找中文字符的起始位置
3. **模式匹配**：使用正则表达式匹配常见模式
4. **字符分析**：逐字符分析确定最佳分割点

### 语言识别

- **原文识别**：日文（平假名、片假名、汉字）或英文字符
- **翻译识别**：中文字符（排除日文假名）
- **混合判断**：根据字符比例判断文本主要语言类型

## 示例输出

### 示例1：日文+中文
**输入：**
```
[00:26.75]流行りの歌はいつも 那些流行的首首歌曲
```

**输出：**
```
[00:26.75]流行りの歌はいつも
[00:26.75]那些流行的首首歌曲
```

### 示例2：英文+中文
**输入：**
```
[00:30.15]Hello world 你好世界
```

**输出：**
```
[00:30.15]Hello world
[00:30.15]你好世界
```

### 示例3：复杂混合
**输入：**
```
[00:44.36]ああ そうやって何千回夜を越える 啊啊 就这么度过了数千个夜晚
```

**输出：**
```
[00:44.36]ああ
[00:44.36]そうやって何千回夜を越える 啊啊 就这么度过了数千个夜晚
```

## 注意事项

1. 确保输入文件使用UTF-8编码
2. 时间戳格式应为 `[mm:ss.xx]`
3. 元数据行（如 `[ti:标题]`）会被保留
4. 对于复杂的混合歌词，可能需要手动调整结果
